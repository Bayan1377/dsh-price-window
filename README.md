# dsh-price-window

Окно тарифа DeepSeek в подвале боковой панели DSH — сразу справа от бейджа баланса.

## Что показывает

- **Пик (дорого):** красная точка и «пик · до 14:00» — полная цена.
- **Офф-пик (дёшево):** зелёная точка `#52b788` и «−50% · до 05:00» — тариф вдвое ниже.
- **Последние 15 минут перед сменой:** точка и подложка берут цвет будущего окна,
  подпись — «через 12 мин», чтобы успеть дописать дорогую операцию в дешёвое время.
- Подсказка при наведении: текущее окно с часами, постоянные пиковые интервалы,
  время смены цены и сколько до неё осталось.

## Клик по бейджу

Клик (или Enter/Space с клавиатуры) раскрывает карточку над бейджем:

- что действует сейчас, окно с часами и остаток времени;
- **день целиком по кускам** — «00:00 – 05:00 −50%», «05:00 – 08:00 дорого» и т. д.,
  конец суток подписывается «24:00», текущий кусок помечен «сейчас»;
- листание дней кнопками **‹ ›** и «сегодня» — от −7 до +7 дней (вместе с праздниками КНР);
- в заголовке дня — сводка: «дорого 7 ч» или «весь день −50%»;
- постоянные правила пика в местном времени и часовая зона;
- таблицу цен `deepseek-flash` за 1M токенов: пик и офф-пик.

Закрывается крестиком, клавишей Esc, повторным кликом по бейджу или кликом мимо.
Карточка рендерится порталом в `document.body`: подвал сайдбара лежит в
transform-контейнере, где `position: fixed` считается от него, а не от окна
(урок L-041).

Часы показываются в местном времени; правила тарифа считаются по UTC, поэтому смена
часового пояса или летнего времени ничего не сдвигает.

## Откуда правила

Официальная страница тарифов DeepSeek (`api-docs.deepseek.com/quick_start/pricing`):

- пик — **01:00–04:00 и 06:00–10:00 UTC**, только по будням;
- всё остальное время, выходные и **праздники КНР** — офф-пик, цены вдвое ниже;
- для `deepseek-flash` пик: вход из кеша $0.006 / промах $0.3 / выход $1.2 за 1M токенов,
  офф-пик — ровно половина.

Праздники КНР в коде пусты намеренно (`HOLIDAYS` в `lib/client.js`): даты объявляет
Госсовет КНР, выдуманная дата показала бы «дорого» в дешёвый день. Новую дату добавлять
строкой `"2026-10-01"` (дата по UTC).

## Состав

| Путь | Назначение |
|---|---|
| `package.json` | Манифест: `dsh.bundle.patch` и `dsh.client` (web, зависимость от sidebar). |

## Установка

```powershell
# пакет лежит в общем каталоге профилей
# ~/.dsh/profiles/node_modules/dsh-price-window
```

В `~/.dsh/profiles/desktop/package.json`:

```json
"dependencies": { "dsh-price-window": "link:../node_modules/dsh-price-window" },
"dsh": { "profile": { "bundles": [ "dsh-price-window" ] } }
```

Запись о строке загрузчика берётся из `cordis.patch.yml` пакета — профильный патч
править не нужно. После установки перезапустить DSH: новый пакет попадает в граф
загрузчика только при старте.

## Проверка

```powershell
$env:ELECTRON_RUN_AS_NODE=1
Set-Location "$env:USERPROFILE\.dsh\profiles\node_modules\dsh-price-window"
& "$env:LOCALAPPDATA\Programs\DeepSeek Harness\DeepSeek Harness.exe" tests\price-window.test.mjs
```

В интерфейсе: бейдж стоит справа от «Баланс …», цвет точки — по текущему окну,
подсказка перечисляет интервалы. В свёрнутой панели (рейка 56 px) бейдж ужимается
многоточием и не ломает раскладку.

## Удаление

Убрать `dsh-price-window` из `dependencies` и `bundles` профиля, перезапустить DSH,
удалить каталог пакета.
